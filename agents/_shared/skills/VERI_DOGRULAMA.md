# Skill: Veri Dogrulama

## Purpose
Tekla metraj verilerini dogrulamak.

## Serves Goals
- Tekla metraj ajanlari parked durumda oldugu icin v1 AutoCAD plaka hattinda pasiftir.

## Inputs
- Metraj raporu
- Tekla model verisi

## Process
1. Parked durumda otomatik kontrol baslatma.
2. Reaktivasyon sonrasi profil, adet ve agirlik tutarliligini kontrol et.

## Outputs
- Dogrulama notu

## Quality Bar
- Model verisi degistirilmez.

## Tools
- Tekla MCP, reaktivasyon sonrasi

## Integration
- Metraj cikarma skill'i ile birlikte calisir.
