# Skill: Metraj Cikarma

## Purpose
Tekla metraj ajanlari tekrar aktive edildiginde modelden metraj cikarmak.

## Serves Goals
- Tekla metraj ajanlari parked durumda oldugu icin bu skill v1 AutoCAD plaka hattinda calistirilmaz.

## Inputs
- Tekla model verisi
- Metraj is emri

## Process
1. Parked durumda calisma baslatma.
2. Insan yeniden aktive ederse Tekla MCP metraj araclarini kullan.

## Outputs
- Metraj raporu

## Quality Bar
- Parked durumda otomatik cikti uretme.

## Tools
- Tekla MCP, reaktivasyon sonrasi

## Integration
- AutoCAD plaka DXF/NC1 hattindan ayridir.
