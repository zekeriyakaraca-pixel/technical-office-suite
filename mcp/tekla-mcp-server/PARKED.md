# Parked Tekla MCP

Tekla is intentionally parked for the first working target of the suite.

The active MVP is:

1. 3D office custom backend.
2. Local FastAPI technical office runtime.
3. AutoCAD PDF to DXF/NC1/QC pipeline.

No old machine-specific Tekla paths are enabled in this suite. When Tekla becomes part of the active path, add a clean local server config here and register it in `../.mcp.json`.
